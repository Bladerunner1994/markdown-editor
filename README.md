# Markdown Editor

A lightweight, fast, and feature-rich in-browser Markdown editor.

## Features
- **Live Preview:** See your rendered markdown instantly as you type.
- **Syntax Highlighting:** Clear formatting for code blocks, headers, and emphasis.
- **Export Options:** Download your work as Markdown or HTML.

## Installation
```bash
git clone https://github.com/Bladerunner1994/markdown-editor.git
cd markdown-editor
npm install
npm run dev
```
